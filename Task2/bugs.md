Отчёты о дефектах API
Баг #1
Краткое описание: API возвращает статус 500 Internal Server Error при создании объявления с длинным полем name (10 000 символов).

Шаги воспроизведения:
Сгенерировать данные для создания объявления, где name содержит 10 000 символов.
Отправить POST‑запрос на /api/ads с этими данными.
Дождаться ответа сервера.
Фактический результат:
Статус ответа: 500 Internal Server Error.
Тело ответа: { "error": "Internal server error" }.
Объявление не создаётся.
Ожидаемый результат:
Статус ответа: 400 Bad Request.
Тело ответа: { "error": "Name must be less than 5000 characters" }.
Объявление не создаётся, но ошибка должна быть валидационной, а не внутренней.
Серьёзность: Высокая (блокирует возможность корректной обработки некорректных данных).
Окружение:

ОС: Windows 11 / macOS Ventura / Ubuntu 22.04 (любая);

Node.js: 18.16.0;

npm: 9.5.1;

API: https://qa-internship.avito.com;

Дата тестирования: 02.04.2026.

Баг #2
Краткое описание: При повторном запросе на создание объявления с идентичными данными возвращается тот же id, нарушая идемпотентность.
Шаги воспроизведения:
Создать объявление с валидными данными.
Повторить тот же POST‑запрос с теми же данными.
Сравнить id в ответе первого и второго запросов.
Фактический результат:
Оба запроса возвращают статус 201 Created.
В обоих ответах содержится одинаковый id.
В базе создаётся только одна запись.
Ожидаемый результат:
Каждый запрос должен возвращать уникальный id.
В базе должны создаваться две отдельные записи с разными id, но одинаковыми данными (согласно бизнес‑логике).
Серьёзность: Средняя (нарушает спецификацию идемпотентности, может привести к ошибкам в клиентских приложениях).

Окружение:

ОС: Windows 11;

Node.js: 16.19.0;

Тестовый фреймворк: Mocha 10.0.0;

Дата тестирования: 02.04.2026.

Баг #3
Краткое описание: Эндпоинт /api/sellers/{sellerId}/ads возвращает статус 500 при несуществующем sellerId.
Шаги воспроизведения:
Сгенерировать случайный sellerId (например, 999999).
Отправить GET‑запрос на /api/sellers/999999/ads.
Проверить статус ответа и тело ответа.
Фактический результат:
Статус ответа: 500 Internal Server Error.
Тело ответа: { "error": "Seller not found" }.
Ожидаемый результат:
Статус ответа: 200 OK.
Тело ответа: [] (пустой массив).
Согласно спецификации, отсутствие продавца не является ошибкой, нужно вернуть пустой список объявлений.
Серьёзность: Средняя (некорректный HTTP‑статус усложняет обработку ответов на клиенте).

Окружение:

ОС: Ubuntu 22.04;

Node.js: 20.5.0;

Axios: 1.4.0;

Дата тестирования: 02.04.2026.

Баг #4
Краткое описание: Поле price принимает отрицательные значения, что противоречит бизнес‑логике.
Шаги воспроизведения:
Подготовить данные для создания объявления: name: "Test", price: -100, sellerId: 123456.
Отправить POST‑запрос на /api/ads.
Получить ответ сервера.
Фактический результат:
Статус ответа: 201 Created.
В ответе возвращается id созданного объявления.
В БД сохраняется запись с price: -100.
Ожидаемый результат:
Статус ответа: 400 Bad Request.
Тело ответа: { "error": "Price must be a positive number" }.
Объявление не должно создаваться.
Серьёзность: Высокая (нарушает бизнес‑правила, может привести к некорректным данным в системе).
Окружение:

ОС: macOS Ventura 13.4;

Node.js: 18.16.0;

Chai: 4.3.7;

Дата тестирования: 02.04.2026.

Баг #5
Краткое описание: Время ответа эндпоинта /api/ads/{id} превышает 2 секунды при высокой нагрузке (100 последовательных запросов).
Шаги воспроизведения:
Создать объявление и получить его id.
Запустить скрипт, отправляющий 100 GET‑запросов подряд на /api/ads/{id}.
Замерить среднее время ответа.
Фактический результат:
Среднее время ответа: 2 300 мс.
Несколько запросов завершились таймаутом (статус 504 Gateway Timeout).
Ожидаемый результат:
Среднее время ответа < 500 мс.
Все запросы должны завершиться успешно (статус 200 OK).
Серьёзность: Средняя (снижает производительность и пользовательский опыт).

Окружение:

ОС: Ubuntu 22.04;

Node.js: 20.5.0;

Нагрузочный тест: скрипт на Mocha + Axios;

Дата тестирования: 02.04.2026.
